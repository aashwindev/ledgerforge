# Retrieval benchmark

Generated by `scripts/bench-retrieval.ts` on pallets/flask history up to 22d92470 (Flask 3.1.3).

**Cases:** 156 real feature and bug-fix commits since 2021 that change `src/flask`. Maintenance commits (dependency bumps, typing, lint, refactors, releases) are filtered out by subject.
**Request:** the commit subject, as written by the Flask maintainers. It is often terse, which makes this harder than a typed instruction.
**Workspace:** the parent commit, so the answer is not in the files yet.
**Answer:** the files the commit changed under `src/flask`, `tests`, `docs` and `CHANGES.rst`.
**Compared:** the Context Pack (8k-token budget, 12.0 files on average) against plain ranked search given the same number of files per case.

| Changed files of this kind | Count | In Context Pack | In plain search, same slots |
|---|---|---|---|
| implementation (src/flask) | 277 | 71% | 71% |
| tests | 82 | 65% | 48% |
| docs pages | 61 | 56% | 56% |
| changelog | 93 | 100% | 95% |
| all changed files | 513 | 73% | 70% |

**At least one changed implementation file in the pack:** 142/156 cases (91%); plain search 137/156 (88%).

Measured on the same 156 cases, before and after adding git co-change to the Context Pack (both within the same 8k-token budget):

| all changed files | 71% | 73% |
